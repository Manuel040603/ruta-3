# Android Basics with Compose — Ruta 3 (Unidad 1)

Repositorio con los ejercicios de la **Ruta 3** de la Unidad 1 del curso
"Tu primera app para Android" — Manuel Torres Chuquiyauri, código
262DSMG1[TU_CÓDIGO].

## Proyectos

| Carpeta | Descripción |
|---|---|
| `HappyBirthday/` | Codelabs 1 y 2: app de saludo de cumpleaños con `Text`, `Column`, `Row`, `Image`, `Box` y modificadores. |
| `ComposeArticle/` | Ejercicio de práctica: artículo con imagen y texto justificado. |
| `TaskManager/` | Ejercicio de práctica: pantalla "todas las tareas completadas". |
| `ComposeQuadrant/` | Ejercicio de práctica: 4 cuadrantes con `Row`/`Column`/`weight`. |
| `BusinessCard/` | Proyecto final libre: tarjeta de presentación personal. |

Cada carpeta contiene el `MainActivity.kt` (y `strings.xml` cuando aplica) para
copiar dentro de un proyecto "Empty Activity" nuevo en Android Studio, con el
mismo nombre de paquete indicado en la cabecera del archivo.

## Cómo ejecutar cada proyecto
1. Crea un proyecto nuevo en Android Studio (Empty Activity, Kotlin, Jetpack Compose).
2. Reemplaza el `MainActivity.kt` generado por el de la carpeta correspondiente.
3. Si el proyecto usa `strings.xml`, copia su contenido a `res/values/strings.xml`.
4. Importa los recursos de imagen que pide cada codelab (`androidparty.png`,
   `bg_compose_background.png`, `ic_task_completed.png`, logo de Android) a
   `res/drawable` o `res/drawable-nodpi` según corresponda.
5. Ejecuta en un emulador o dispositivo físico.
